  Reading: a negative slope means the countries in that grouping grew more

========================================================================
(B) BETA-CONVERGENCE — catch-up across the 14 countries
========================================================================
Specification: (1/21) * ln(TFR_end / TFR_start) = alpha + beta * ln(TFR_start)
Endpoints are 3-year averages: start = mean(2000-2002), end = mean(2021-2023).
n = 14 countries. HC3 standard errors with small-sample t inference.

  UNCONDITIONAL beta-convergence:
    beta = +0.0013  (HC3 SE 0.0116, p = 0.911)
    95% CI [-0.0240, +0.0267]     R2 = 0.004
    => Positive: no evidence of catch-up. Initially higher-fertility
       countries did NOT decline faster; if anything the opposite.

  CONDITIONAL beta-convergence (adds the Central Asia dummy):
    ln_tfr_start    : -0.0201  (HC3 SE 0.0267, p = 0.467)
    ca              : +0.0176  (HC3 SE 0.0187, p = 0.368)
    R2 = 0.270
    Reading: the CA dummy asks whether Central Asian countries followed a
    different trajectory once their 2000 starting level is accounted for.
    A positive CA coefficient means Central Asia declined less (or rose
    more) than its starting level alone would predict.

  CAVEAT (Galton's fallacy, Quah 1993): beta-convergence is necessary but
  NOT sufficient for sigma-convergence, and a negative beta can arise from
  regression to the mean if initial TFR is measured with error. Read
  sections (A) and (B) together, and treat both as descriptive summaries
  at n = 14.

========================================================================
(E) PROJECTION-SENSITIVITY CHECK (descriptive only)
========================================================================
master_tfr.csv carries 'estimate_method', distinguishing WPP retrospective
'Interpolation' from forward-looking 'Projection' values (20 of 336 rows,
concentrated in 2020-2023 and in every country's 2023 observation; see
01_clean_data.py). The (B2) post-2017 CV slope and the (B) beta-convergence
coefficient above both partly rest on these projected endpoints. This block
re-computes those two headline descriptive results under two BALANCED
sub-samples, each holding a FIXED country set across all years it uses. An
earlier version of this check instead dropped projected ROWS year-by-year,
which let the country set drift over time (14 -> 12 -> 11 -> 10 countries,
collapsing to 3 low-fertility countries by 2023). That composition drift, not
genuine convergence, drove a spuriously negative post-2016 slope. A valid
cross-time dispersion comparison requires the SAME countries in every year
compared, so both samples below fix the country set before comparing years:
  (a) full 2000-2023, all 14 countries (baseline, as reported above)
  (b) Sample A - balanced historical: all 14 countries, 2000-2019, no
      projected values anywhere in that window
  (c) Sample B - balanced interpolation-only recent: countries with a
      non-projected observation in EVERY year 2017-2022, that country set
      then held fixed for all years used (list below; membership is
      derived from the data, not hardcoded)
This is NOT a significance test: no p-values or significance claims are made
here, and the sub-samples are smaller than the already-small n=14/T=7 used
above.

  Sample B country set (n=10, non-projected in every
  year 2017-2022): Azerbaijan, Estonia, Georgia, Kazakhstan, Kyrgyzstan, Latvia, Lithuania, Moldova, Russia, Uzbekistan

  Sample                                          CV slope 2000-16  CV slope post-16      beta  n (beta)  excl  end window used
  (a) Full 2000-2023 (baseline)                           -0.00715          +0.01954   +0.0013        14     0  2021-2023 (post-16: 2017-2023)
  (b) Sample A: balanced historical (2000-19)             -0.00715          +0.02365   -0.0085        14     0  2017-2019 (post-16: 2017-2019)
  (c) Sample B: balanced interp-only recent               -0.00333          +0.02613   +0.0052        10     0  2020-2022 (post-16: 2017-2022)

  READING: the post-2016 CV slope is POSITIVE (rising dispersion) in all
  three samples once the country set is held fixed — full sample
  (+0.0195), Sample A (+0.0236,
  though only 3 annual points, 2017-2019), and Sample B
  (+0.0261, 2017-2022, the best-powered of the
  three, n=10 countries, rising monotonically across those six years). The
  post-2017 divergence in the headline result is therefore CONFIRMED by this
  check, not called into question: it is not an artifact of WPP projections
  or of a shrinking, low-fertility-biased country set.
  Beta-convergence: full sample beta = +0.0013; Sample A (end
  window 2017-2019, before most of the post-2017 divergence had
  accumulated) beta = -0.0085; Sample B beta = +0.0052.
  All entries in this block are descriptive point estimates; treat as a
  sensitivity check, not a formal robustness test.
